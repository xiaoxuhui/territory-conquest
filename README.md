# 疆界 · 领土争夺

零依赖的浏览器实时策略游戏。入口为 `dist/index.html`，使用 ES modules，需由 HTTP 服务打开。

本地运行：`node server.cjs`，然后访问 http://127.0.0.1:8261 。

## 玩法

每个阵营以一格领土、20 兵力开局。左键选中己方格子，再点击上下左右相邻格子进攻或增援。占领后自动选中新格；再次点击已选中的格子可以取消。支持 50% / 全部出兵，至少留守 1 人。出兵数必须大于敌方守军才能攻下；兵力相等时守方保留领土，兵力归零。

每 1.6 秒所有阵营的普通领土增加 1 兵力，自己的初始据点增加 3（增长上限 999，集结可超过此值）。初始据点被敌人占领后是普通领土，原阵营收复后恢复据点增兵。难度影响电脑思考间隔和决策，所有阵营兵力增长相同。占领全图获胜，失去全部领土后可以继续观战。

六个关卡和自定义模式（1–7 位电脑、三档地图、三档难度）。可暂停、双倍速、重新开始。关卡通关记录仅保存在当前浏览器，战局不跨刷新保留。键盘方向键出兵，空格暂停（焦点位于按钮时遵循按钮原有键盘操作），Esc 取消选中。

`dist/engine.mjs` 为独立规则与 AI；`dist/app.mjs` 为界面和游戏循环；`node --test test/engine.test.mjs` 运行规则测试。
