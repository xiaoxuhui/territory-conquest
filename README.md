# 疆界 · 领土争夺

零依赖的浏览器回合策略游戏。入口为 `dist/index.html`，使用 ES modules，需由 HTTP 服务打开。

本地运行：`node server.cjs`，然后访问 http://127.0.0.1:8261 。

## 玩法

每个阵营以一格领土、20 兵力开局。左键选中己方格子，再点击上下左右相邻格子进攻或增援。占领后自动选中新格；再次点击已选中的格子可以取消。支持 50% / 全部出兵，至少留守 1 人。出兵数必须大于敌方守军才能攻下；兵力相等时守方保留领土，兵力归零。

有人类玩家存活时，每位人类依次成功出兵或蓄兵一次，然后每个存活电脑最多行动一次，最后统一增兵。多个人类玩家由同一台设备的同一鼠标轮流控制；当前玩家、阵营名称和颜色会明确显示，无法操作另一位玩家的领土。此时电脑不会在思考、选格、悬停或等待期间自动行动，兵力也不会随时间自动增长。无效操作不消耗行动。点击「蓄兵一回合」或按 E 可以放弃当前玩家的出兵机会。

全是电脑时，观战界面可以选择两种运行模式：「走一步停一步」每次点击「推进一回合」或按 E，让每个电脑最多行动一次，再统一增兵，然后停下；「一直走」在开始观战后自动连续运行。默认一直走。运行中可随时切换，不重开、不重置兵力；切为单步时先完成当前回合，再停下。也可以暂停、继续、重开。所有人类出局后选择「继续观战」也能使用这两种模式。电脑数为 0 时，无论单人还是多人，始终由你手动操作，不会自动代走。有人类玩家存活时不显示电脑运行模式。比赛结束后停止。

纯电脑观战支持 1×、2×、4×、8× 运行速度，可在开局前或运行中切换，不重开战局。连续模式同时加快行动播放和回合等待；单步模式只加快回合内播放，每次仍仅推进一回合。暂停时所有速度都冻结。切回人类控制后恢复正常速度，人类行动与电脑行动次数规则不受倍速影响。

电脑使用「扩张、集结、稳步推进」策略：优先补齐接壤空地；选定一个突破目标，将后方兵力沿己方领土汇集到同一个出发点；估算相邻敌军的反击能力，够兵才进攻，兵力充裕时优先使用半数出兵留守。突破后优先沿当前战线继续推进。简单难度更随机、较少防范反击，困难难度更谨慎。策略不修改行动次数、战斗伤亡、增兵或胜利条件。

一轮行动结束后所有阵营的普通领土增加 1 兵力，自己的首都增加 3（增长上限 999，集结可超过此值）。与敌军交战的进攻格和受攻击格本回合都不自动增兵，双方规则相同；下一回合若不再交战则恢复增长。首都被敌人攻占后，原首都失效并成为普通领土；收复该格也不会自动恢复首都。可选己方普通领土点击「建设首都」，消耗一次行动建设新首都。每个阵营最多两座首都，建成后可再次迁都。难度只影响电脑决策，所有阵营的行动次数和兵力增长规则相同。占领全图获胜。

界面先显示战斗扣兵，再逐个显示电脑行动，最后显示统一增兵，结算期间不能重复出兵。地图下方保留本次进攻的出兵数、守军扣减算式和后续增援；增援是从相邻己方格子实际调入，源格也扣除相应兵力。右侧势力列表显示阵营总兵力，地块数字显示该格守军。

六个单人关卡和自定义模式（三档地图、三档电脑难度）。自定义人类与电脑人数均可为 0，合计 1–8 位：单人零电脑练习、多个人类零电脑同机对战、混合人机对战、零人类电脑自动观战均可。至少保留一个阵营，合计达到八位后不能继续增加；无电脑时难度按钮禁用。人类玩家失去全部领土后会跳过其行动，其他存活人类仍可继续操作，任一人类或电脑占满全图才获胜。

可暂停、重新开始。关卡通关记录仅保存在当前浏览器，战局不跨刷新保留。键盘方向键出兵，E 蓄兵一回合，空格暂停（焦点位于按钮时遵循按钮原有键盘操作），Esc 取消选中。计时器只统计思考用时，不影响战局。

`dist/engine.js` 为独立规则与 AI；`dist/app.js` 为界面和游戏循环；`node --test test/*.mjs` 运行规则与打包测试。

资源包内脚本一律使用 `.js` 扩展名：大厅按固定 MIME 表发放文件，只有 `.js` 映射为 JavaScript，`.mjs` 会被当作二进制下载，模块脚本因严格 MIME 检查而无法启动。

尚有首都时，选中己方普通领土后点击「迁都」即可移动首都，消耗当前玩家的一次行动。兵力留在原格；旧首都恢复每回合 +1，新首都每回合 +3。每个阵营最多两座首都。首都失守不会立即淘汰阵营，仍以全部领土归属判定胜负。

建设首都不转移或扣除兵力，只消耗当前玩家的一次行动，新首都从本轮结算起按首都规则增兵。已有两座时不能继续建设，同一格不能重复建设；电脑失去首都后也会用自己的一次行动选择较安全的己方领土建设，不会自动恢复原首都。两座首都时，迁都前可以选择迁出的首都；只移动这一座，另一座保留。一座首都被攻占不会使另一座失效。电脑完成空地扩张后也可花一次行动在安全地块建设第二座。

地区动荡与分裂：最近 8 回合累计 4 次被中立态度的进攻方攻占，会在回合末独立。所有己方调兵、集结和增援都不增加动荡；占空地和未攻占的战斗也不增加动荡。安定 8 回合后相关记录消失。分裂中心与相连且动荡至少 2 的同阵营领土，最多 3 格组建新国；每个独立地块兵力变成该格独立前的 10 倍，中心成为新首都。新国由电脑从下一回合开始每轮行动一次，享有 12 回合稳定期，之后也会分裂。初始仍最多 8 个阵营，建国可以增加新阵营；所有玩家使用相同规则。领土情报、地图叹号、战报和势力柱状图均显示动荡或建国情况。

有方向的外交关系：初始各国互相中立，每个方向单独记录和平（0）、中立（1）、敌对（2）。A 有效进攻 B（包括未攻占）只使 B 对 A 降低一级，A 对 B 不变。己方调兵、占空地和无效操作不改变外交。动荡记录保存进攻者、受击者及地区原属国；因战乱建国的新国对地区原属国和平、对进攻者敌对，不把收复地区的原属国误认作敌人。新国关系同样不是双向强制同步。和平态度禁止攻击对方；中立电脑每回合有 1% 概率主动进攻中立国家，受攻击后可正常反击；玩家可手动决定中立出兵，此概率不改变战斗胜率；敌对态度允许主动攻击，电脑优先投入敌对战线而非继续占空地。玩家在外交面板查看己方国家可宣战，消耗一次行动，仅改变自己的态度为敌对，对方在实际受到攻击前保持原态度。所有国家互相和平时可以共存，胜利仍需占领全图。外交面板可切换存活国家，同时查看两方向态度；领土情报与战报也显示相关变化。

中立主动进攻使用每个电脑每回合最多一次的概率判定（小于 0.01 即允许）。该回合内再次查询、渲染或重复调用不会重抽概率；没有接壤的中立国家不判定。其他新国关系默认中立，战争独立的新国对原属国明确设为和平，对进攻者敌对，反向仍独立。
外交缓和等级：和平 > 中立 > 敌对。每个完整回合末，对每对已接触的存活国家只判定一次 1% 概率（与中立进攻概率分开）。不同态度时，较敌对方直接变成对方的较友好态度；相同态度时双方同时升一级，和平封顶。暂停、思考、反复渲染不会重抽。外交缓和在本回合建国前结算，新国下回合起参与；建国兵力按各格独立前的结算后兵力乘 10，只在建国瞬间应用一次，不受普通增兵的 999 上限截断。
敌对作战免除本次攻占的分裂动荡：以出兵瞬间进攻方对守方的态度判断，敌对进攻即使攻占也不新增 capture 动荡；守方因受击而变为敌对不会反过来改变本次进攻的性质。此前其他原因的动荡继续按原规则衰退，所有己方调兵都不增加动荡，旧的 drain 记录也不计入动荡与分裂。规则同样适用于人类、电脑和新国。
逐格小队行军：沿用普通格子和相邻出兵，不增加远程按钮或瞬移。和平国家、或未接壤但仍保持敌对的国家，每轮最多一次 1% 小队发起机会；有近邻敌人时优先正常战线。派兵为原格兵力约 10%、至少 1 人、最多 5 人且留守 1 人。小队每轮占用一次既有电脑行动，只走相邻己方或空白地块，逐格接近目标；抵达边界时敌对小队按正常兵力抵消进攻，和平小队把实际派出兵力转给对方并结束，不改变土地或外交。初始陌生国家保持中立，不作为外交行军目标；每个国家最多一个行军目标；没有路线、队伍领土失守、目标出局或外交变化时取消。和平援军遇到己方周边战事时让位于正常战线。

国家接触规则：仅当任意己方地块的上下左右存在对方领土时，才视为两国接触。未接触时或领土变化导致接触中断时，两个方向分别保持当前态度，跳过随机缓和及恶化，不消耗这部分随机数，不强制重置为中立。未接触不能直接宣战，外交面板显示距离较远和保持原态度。再次接触沿用原态度，继续执行单向攻击反应、1% 缓和及每方向 1% 恶化规则。
外交恶化：和平至中立至敌对，敌对封底，仅改变被抽中的方向。每对接触国家每回合抽一次随机数：[0,0.01) 缓和，[0.01,0.02) A 对 B 恶化，[0.02,0.03) B 对 A 恶化，其余不变。因此缓和和两个方向恶化各为 1%，且同一对国家同回合不会先升后降。远距离不抽取这些概率，双方保留当前不同态度。
